# Detalles MOSS PWA

Esta aplicación es una PWA (Progressive Web App) sencilla para la venta de detalles en línea.

## Ejecutar

1. Instale un servidor web simple, por ejemplo `npm install -g serve`.
2. Ejecute `serve .` en el directorio del proyecto y abra la dirección que indique en su navegador.

La aplicación permite seleccionar hasta 8 opciones de detalles y pagar mediante PSE, Nequi, Daviplata o Wompi.
